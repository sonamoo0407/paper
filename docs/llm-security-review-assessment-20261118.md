# 최고 매개 후보 LLM 보안 리뷰 검토

검토일은 2026-11-18이며 공개 arXiv v5와 이번 피싱 인용망을 기준으로 한다. 대상 논문은 *Large Language Models for Cyber Security: A Systematic Literature Review*다. arXiv 식별자는 `2405.04760`, 출판 DOI는 `10.1145/3769676`이다.

## 연구 자료로서의 평가

보안 분야의 LLM 연구와 관련 논문을 찾는 데 읽을 가치가 큰 리뷰로 판단했다. 약 4만 7천 건의 검색 후보에서 185편을 선정했고 포함·제외 기준, 품질평가, 앞뒤 인용 추적을 설명한다. 보안 작업·사용 모델·적용 기법·데이터 관점의 분류는 연구 질문을 좁히고 문헌 선정 절차를 설계하는 참고가 된다. [논문 방법론](https://arxiv.org/html/2405.04760v5#S2)

분석 대상이 소프트웨어·시스템 보안에 집중돼 있어 피싱 탐지에 대한 판단에는 개별 실험 논문을 추가 검토해야 한다. 게재처와 길이 중심 선별이 만드는 범위 편향도 고려한다. [공개 v5 원문](https://arxiv.org/html/2405.04760v5)

구체적인 기술 설명의 원출처 대조가 필요하다. 공개 v5의 8.1.1절은 CodeGen 등을 1천억 파라미터 이상으로 기술하지만 인용한 CodeGen 원 논문은 최대 161억 파라미터라고 명시한다. [리뷰 해당 절](https://arxiv.org/html/2405.04760v5#S8.SS1.SSS1), [CodeGen 원 논문](https://arxiv.org/abs/2203.13474)

## 이번 인용망에서 높게 나온 이유

| 매개중심성 | 0.000591 |
| 들어오는 간선 | 1 |
| 나가는 간선 | 104 |

들어오는 논문은 `KGL-228`, *LLM Comparison For Phishing Detection Using Machine Learning*다. 현재 표본에서는 이 논문이 리뷰를 거쳐 많은 참고문헌에 연결되므로 리뷰의 범위와 관측 그래프가 순위에 크게 작용한 것으로 해석한다. 서로 다른 독립적 연구 집단을 잇는 내용상 역할은 추가 확인이 필요하다.

해당 입력 간선의 목적도 재검토 대상이다. 표시된 문맥은 LLM이 전통적인 분석 도구를 조율한다는 설명인데, 현재 장부에는 비교·검증으로 분류돼 있다. 표시 문맥만으로는 배경 소개에 가까울 가능성이 있다. 두 분류의 현재 배점은 모두 +0.5지만 목적 설명을 구분해 검토해야 한다.

이 검토는 [보존한 최종 그래프](../reports/phishing_windows_handoff_20261118/graph.html)의 결과를 읽은 후속 분석이다. 문맥 분류와 원문 기술 설명을 별도로 확인하는 사례로 사용한다.
