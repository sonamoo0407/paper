# 경기대 도서관 수집기 운영 기록 (2026-10-06)

## 목적

`ransomware detection` 등 연구 키워드에서 경기대 도서관 EDS의 후보 메타데이터를 먼저 수집하고, 적법하게 확보한 원문만 이후의 로컬 분석과 Hermes 연구 흐름에 연결한다.

## 구성

| 단계 | 실행 주체 | 산출물 | 모델 토큰 |
| --- | --- | --- | --- |
| EDS 메타데이터 수집 | 로컬 Python | `records.jsonl`, `records.csv`, `manifest.json` | 사용 안 함 |
| 중복 제거·순위화·후보 선별 | 로컬 Python | `selected_candidates.jsonl` | 사용 안 함 |
| PDF 텍스트·참고문헌 추출 | 로컬 Python | `pdf_extraction.jsonl` | 사용 안 함 |
| 인용 그래프 데이터/HTML 생성 | 로컬 Python | 그래프 JSON·HTML | 사용 안 함 |
| 연구적 해석·최종 선정 사유 | Hermes/사람 | 검토 기록·보고서 | 필요 시 사용 |

## 현재 확인된 흐름

1. 공개 EDS 검색에서 키워드별 후보 메타데이터·DOI·연결 주소를 수집한다.
2. 기관 구독 자료는 사용자가 자신의 경기대 권한으로 로그인한 Chromium 세션에서 접근 상태를 확인한다.
3. IEEE 후보는 EDS의 전자저널 경로를 거쳐 `Full Text (IEEE)` 또는 문서 상세 페이지의 PDF 제어로 이동할 수 있음을 화면에서 확인했다.
4. 프록시 PDF 뷰어가 열린 경우 실제 내려받기 파일은 `%PDF-` 헤더와 파일 크기로 검증한 뒤에만 분석 입력으로 등록해야 한다.

## 검증 상태와 제한

- EDS 메타데이터 수집: 확인됨.
- 로그인 상태 판별: `로그아웃` 등 세션 신호로 확인하는 흐름을 사용함.
- 기관 프록시 PDF 자동 저장: **검증 진행 중**. 뷰어 도달은 확인했지만, 브라우저 내려받기 제어를 자동 실행해 파일 생성·헤더 검증까지 완료한 성공 기록은 아직 없다.
- 자동화는 접근 제한·유료 구독·CAPTCHA·MFA를 우회하지 않는다. 실제 표시된 CAPTCHA/MFA/동의는 사용자만 직접 처리한다.
- 비밀번호·쿠키·세션값은 저장·출력·Git 커밋 대상이 아니다.

## 다음 성공 조건

후보 한 편에서 다음을 모두 만족하면 PDF 확보 단계를 성공으로 처리한다.

1. 합법적 로그인 세션에서 전자저널/PDF 제어가 보인다.
2. PDF 뷰어의 내려받기 동작으로 로컬 파일이 생성된다.
3. 파일의 크기가 0보다 크고 첫 바이트가 `%PDF-`다.
4. 제목·DOI·다운로드 시각·원본 경로·SHA-256을 장부로 남긴다.
5. 확보 파일만 `ROOT_PAPER_IMPORT`에 넣고 `preserve_pdf`로 연구 실행 폴더에 등록한다.

## 저장소 범위

수집기 소스와 실행 보조 파일은 `tools/kyonggi-library-collector/`에 포함한다. `.venv`, `outputs`, 브라우저 프로필, 다운로드 PDF, 인증 정보는 포함하지 않는다.
