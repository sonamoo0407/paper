# 논문 선정 및 원천 추적 보고 요구사항

2026-09-14 사용자 요청. 이 문서는 목표 출력과 검증 기준이며 모든 항목이 구현됐다는 뜻은 아니다.

## 출발 논문 5편과 주요 루트 후보의 필수 항목

- 정확한 제목, 전체 저자, 확인 가능한 소속.
- 최초 공개일, 정식 발행일, 사용 버전의 수정일을 구분. 미공개 작성일은 확인 불가로 표시.
- 학회·저널, 논문 유형, DOI·논문 ID, 공식 페이지·PDF 링크, 원본 보존 기록.
- 쉬운 한국어 한 줄 요약, 문제, 연구질문, 주장, 방법, 증거, 결론, 한계.
- 초록만 읽었는지, 본문을 읽었는지, 실험 재현 여부를 명시.
- 저자 주장, 원문 확인 사실, 분석자 해석, 확인 불가를 구분.
- 공식 게재 확인과 학회 기준선 분류를 분리. arXiv 공개만으로 탑티어 게재를 확정하지 않음.

## 구체적인 선정 이유

연구 질문과의 연결, 활용 가능한 방법·데이터·평가, 대안보다 우선한 이유, 다른 출발 논문과의 중복·보완성, 한계와 제외 이유를 근거와 함께 적는다. 연구 방향은 사용자 확정 사항과 분석자의 제안을 구분한다. 제목 일치·인용 수만으로 선정 이유를 대체하지 않는다.

## 여러 단계의 원천 추적

- 출발 논문에서 참고문헌으로, 다시 그 참고문헌의 참고문헌으로 관련 경로를 확장한다.
- 개념·방법·데이터셋별 기원 후보를 구분하고 관련 가지를 우선한다.
- MITRE 공식 기술보고서나 프레임워크 문서가 근원 후보이면 논문과 자료 유형을 구분해 포함한다.
- 각 후보까지의 출발 논문·중간 논문 전체 경로와 단계 수를 보존한다.
- 서로 다른 출발 논문의 도달 수와 직접 인용 수를 구분한다.
- DB 참고문헌 연결과 원문 인용 문맥 확인을 구분하고, 미확인 연결을 확정하지 않는다.
- 중복·순환을 처리하고 제외·보류한 가지와 이유도 보존한다. 일반 배경 이론도 연구 질문에 필요한 경우 유지한다.
- 가장 오래됨, 높은 공통 인용 수, DB 참고문헌 0건을 최초성의 증거로 사용하지 않는다.
- API 오류·원문 미확보·깊이·노드·호출 예산 도달은 탐색 미완료로 표시한다.
- 계속 탐색할 대기열과 원래 출발 논문 연결을 보존한다. 도구 상한과 실제 도달 깊이를 보고한다.

현재 반복 호출 간 그래프 통합·대기열 재개를 포함한 전체 기능의 구현 완료는 확인되지 않았다. 단일 호출 제한을 늘리는 것만으로 이 요구사항이 충족되지는 않는다.

## 산출물
