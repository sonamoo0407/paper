# MITRE ATT&CK 2차 참고문헌 확장 기록

- 작성일: 2026-09-14
- 목적: 1차 인용 그래프에서 공통으로 도달한 ATT&CK 관련 후보를 다시 시작점으로 삼아, 더 이른 관련 연구·공식 자료 후보를 탐색한다.

## 방법

- 시작점: 1차 그래프의 공통 도달 상위 후보 7개
- 탐색 방향: 논문 → 참고문헌 → 참고문헌의 참고문헌
- 실행 한도: 깊이 2, 최대 노드 100, 참고문헌 상한 100
- 관계 근거: 학술 메타데이터 서비스의 참고문헌 관계. 원문 PDF 인용 문맥 확인과는 구분한다.

## 결과

- 후보: 95개
- 조회 실패: 2개
- 완전히 해석된 시작 후보: 5/7
- 상태: `탐색 미완료`

공식 ATT&CK Navigator와 `attack.mitre.org`로 향하는 자료형 인용이 나타났다. 이는 ATT&CK 개념의 근원 후보가 논문만이 아니라 MITRE의 공식 프레임워크·도구·기술 문서에 있을 수 있음을 뜻한다. 단, 정확한 문서 판본·버전·발행일과 원문 인용 문맥은 아직 확인하지 않았다.

## 잡음과 제외 원칙

인용 그래프에는 일반 정보이론, 주제 외 방법론처럼 ATT&CK 연구와 직접 관계없는 항목도 나타났다. 다음 조건을 만족하지 못하면 원천으로 확정하지 않는다.

1. ATT&CK 개념·방법·데이터·평가 중 하나와 직접 연결되는가
2. 출발 논문 또는 중간 논문에서 어떤 역할로 인용되는가
3. 공식 기록 또는 원문 PDF로 관계를 확인할 수 있는가

일반 이론이 오래됐거나 그래프에서 공통으로 나타난다는 사실만으로는 연구의 최초 원천이 아니다.

- API 조회 성공·실패 수는 완전탐색의 증거가 아니다.
- PaperQA, 외부 LLM·임베딩 모델, 논문 코드 실행은 이 탐색에서 사용하지 않았다.
- 이 문서는 공개용 직접 작성 요약이며, API 원응답·원문 PDF·원문 HTML은 포함하지 않는다.
