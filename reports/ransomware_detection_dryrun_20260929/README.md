# ransomware detection 소형 1사이클 드라이런

## 목적

정식 100편 실험 전에 `ransomware detection` 키워드로 검색 → 제한된 후보 선정 → 확인 가능한 참고문헌 메타데이터 추적 → 로컬 클릭형 그래프 → 실제 포인터 클릭 검수를 한 번 끝까지 검증한 기록이다.

## 1사이클 흐름과 결과

1. 공개 Crossref 메타데이터와 경기대학교 도서관 통합검색을 같은 키워드로 확인했다.
2. R1 직접 후보는 최대 5편 제한으로 수집했다.
3. R1 5편 중 참고문헌 메타데이터에 DOI 근거가 있는 1편(`R1-02`)만 최종 후보로 선정했다.
4. 그 논문의 Crossref 참고문헌 메타데이터에서 실제 DOI가 확인된 R2 2편만 보존했다.
5. 노드 3개·방향 간선 2개 로컬 그래프를 만들고 실제 포인터 클릭을 검수했다.

이 번들의 근거 수준은 **메타데이터**다. R2 간선은 원문 참고문헌 페이지를 읽어 확인한 것이 아니라, Crossref 참고문헌 메타데이터의 DOI·참고문헌 번호를 근거로 한다.

## 그래프 사용법

`graph/index.html`을 로컬 브라우저로 열면 된다.

- 기본 상태: 노드 외곽끼리 이어진 일반 선만 보인다.
- 노드 클릭: 해당 노드 인접 간선에만 `인용한 논문 → 인용된 논문` 화살촉과 우측 근거가 표시된다.
- 우측 `분석 메모`: 별도 분석 텍스트가 없음을 표시하고, 실제 장부·로그 경로와 메타데이터 범위의 한 줄 요약을 보여준다.
- 오른쪽 아래 `☰ R1 전체 후보`: 이번 드라이런에서 조사한 R1 5편의 제목 목록을 연다.

공개 HTML의 `${RESEARCH_DATA}`는 로컬 연구 데이터 루트를 뜻하는 이식용 표기다.

## 결과물 위치

- R1 후보 장부: `ledger/r1_candidates.json`
- R2 인용 장부: `ledger/r2_citation_ledger.json`
- 검색·접근 상태 로그: `logs/search_log.json`
- 그래프 데이터/예시 HTML: `graph/graph.json`, `graph/index.html`
- 제한·그래프 수·금지 동작 검증: `verification/dryrun_verification.json`
- 실제 클릭·분석 메모 검증: `verification/analysis_note_verification.json`
- 클릭 검증 코드: `verification/verify_analysis_note.py`

## 경기대 도서관 한계와 다음 정식 실행 조건

이번에는 **비로그인 공개 통합검색의 결과 수·노출 메타데이터·접근 라벨만** 확인했다. 기관 구독 전문은 확인하지 않았고, 도서관 개별 레코드를 R1 후보 선정 근거로 사용하지 않았다.

정식 실행에서 기관 DB 결과를 후보에 반영하려면, 사용자가 직접 로그인한 활성 경기대 도서관 세션에서 실제 통합검색 또는 선택 DB를 열어 개별 결과의 서지정보와 접근 상태를 확인해야 한다. 각 후보에는 DB명·검색식·시각·결과 수·공식 식별자·전문 상태·선정 근거를 공개 검색 장부와 함께 기록하고, DOI·제목 기준 중복 제거 뒤 R1 장부에 반영한다. 로그인 비밀번호·쿠키·인증정보는 저장하거나 커밋하지 않는다.

## 제외 범위

이 공개 번들에는 PDF, 원시 API 응답, 브라우저 프로필·쿠키·인증정보, `.env`, 가상환경, 캐시, 임시 스크린샷, 중간 UI 변형을 넣지 않았다.
