# 인용 문맥 채점 규칙

방향은 인용한 논문 → 인용된 논문으로 기록한다. 참고문헌과 본문 인용을 대조하고, 논문 쌍에 채점을 한 번 적용한다. 같은 인용을 본문에서 여러 번 사용하면 근거를 모아 두고, 방법 채택이 확인된 경우 배경 소개보다 채택을 우선한다.

| 분류 | 문맥 점수 | 판정 근거 |
| --- | ---: | --- |
| 배경·단순 소개 | +0.5 | 배경 설명이나 관련 연구에서 논문·방법을 소개한다. |
| 방법 채택·발전 | +1.5 | 방법·개념 등을 실제로 사용하거나 발전시켰다는 설명이 있다. |
| 판정 보류 | +0.2 | 인용 관계는 확인했으나 본문을 확보하지 못했거나 인용 목적이 모호하다. |
| 비교·검증 | 미정 | 비교 대상 또는 검증 기준으로 사용한 문맥을 기록한다. |
| 한계 지적 | 미정 | 구체적으로 지적한 한계와 그 문맥을 기록한다. |

비교나 한계 지적을 확인하면 해당 분류와 근거를 보존한다. 감점 폭은 합의 전까지 미정이다. 인용 관계 자체가 아직 미확인이면 채점 대상에서 제외한다. 보류를 해소하면 +0.2를 확정 점수 또는 미정으로 교체한다.

간선마다 인용한 논문 ID, 인용된 논문 ID, 참고문헌 번호, PDF 페이지, 인용 문장과 필요한 주변 문맥, 분류와 판단 이유를 남긴다. 중간 논문을 설명할 때는 어떤 연구 흐름을 연결하고 두 인용 문맥에서 무엇이 이어졌는지 확인한다.

보고서에는 매개중심성, 문맥 점수, 원문 근거를 함께 표시한다. 둘을 합치는 공식은 미정이다. 사용자에게는 후보 선정 이유, 인용 근거, 그래프와 분석 파일 위치를 담은 검증된 최종 산출물을 공유한다.

2026-11-11 헤르메스는 이 규칙의 VM 내 문서화와 R1·R2 PDF 74편의 문맥 추출 시작을 보고했다. 이후 사용량 제한 보고가 있었고, 추출 완료·채점 자동화·최종 그래프 재생성·현재 VM 적용 여부는 확인이 필요하다.
