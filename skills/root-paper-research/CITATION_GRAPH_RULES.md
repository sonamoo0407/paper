# citracer 기반 인용 그래프 지침

모든 주제에서 오픈소스 citracer의 분석과 HTML 렌더링을 사용한다. 구현과 화면의 기준은 [랜섬웨어 렌더러](../../scripts/render_ransomware_citracer.py)와 [결과 HTML](../../docs/ransomware-citracer.html)이다. 입력은 해당 주제의 검증된 인용 장부와 문맥 장부를 사용한다.

citracer의 기본 화면과 검색·배치·필터·내보내기 조작을 유지한다. 기본 배치는 위에서 아래로 R1 → R2 → R3를 표시하는 Sugiyama 깊이순으로 설정하고, 선택한 논문과 인용 근거 패널은 그래프 아래에 둔다.

EDS와 DOI 또는 참고문헌에서 확인한 출판연도를 출처와 함께 장부에 기록하고 citracer 노드의 `year`까지 전달한다. 출판연도를 확인할 수 없거나 동일 DOI에 상충하는 연도가 있으면 미확인 상태를 유지한다. 깊이순과 연도순을 모두 실행해 연도가 있는 노드의 배치가 달라지는지 검수한다.

- 논문마다 노드 하나를 만들고, 같은 DOI는 정규화하여 합친다. R1·R2·R3 역할은 보존해 색과 상세 정보에 표시한다. 같은 방향의 인용 논문 쌍은 간선 하나로 만들고 참고문헌과 본문 근거는 함께 보존한다. 화살표는 인용한 논문에서 인용된 논문으로 향한다.
- 확정된 방향성 인용망에서 citracer로 매개중심성을 다시 계산한다. 노드 크기의 기본값은 매개중심성이며, 제목 검색과 상세 패널, 중간 논문 후보 순위, R1 선정 이유를 제공한다. 복수 역할이 있는 논문도 한 곳에서 클릭할 수 있게 한다.
- 선택한 인용 간선의 실제 인용 문장, 주변 문맥, PDF 페이지, 목적, 판정 이유, 적용 점수를 표시한다. 연구 흐름을 잇는 중간 논문을 해석할 때는 들어오는 인용과 나가는 인용의 근거를 함께 확인한다. [채점 규칙](CITATION_CONTEXT_RULES.md)을 적용하고 매개중심성과 문맥 점수는 각각 표시한다. 합산 순위는 별도 기준이 확정되면 적용한다.
- 공유 전에 고유 노드와 간선 수, 중복 DOI, 간선 양 끝의 노드, 문맥 장부의 매칭 결과와 미매칭 건수를 확인한다. R1→R2와 R2→R3에서 각각 대표 인용을 골라 원문과 목적 분류를 대조하고, 제목·노드 크기·상세 패널을 실제 브라우저에서 확인한다.
