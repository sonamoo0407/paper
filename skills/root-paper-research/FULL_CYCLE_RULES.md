# 논문 연구 1사이클 실행 지침

수집부터 산출물까지 요청받으면 같은 실행 ID로 다음 순서를 진행한다.

1. EDS 검색과 서지 장부 수집, 중복 제거, 후보 선정 근거 기록
2. 원문 PDF 확보 및 검증, 실패 사유 기록과 다음 후보 처리
3. R1 → R2 → R3 인용 추적과 인용 문맥 추출 및 채점
4. citracer HTML 생성과 실제 브라우저 검수
5. 검수를 통과한 HTML을 공유 폴더에 내보낸 뒤 원본과 공유 파일의 해시 일치 확인

각 단계에서 실행 ID, 단계 상태, 산출물, 완료한 건수, 다음 실행 위치를 기존 상태 파일이나 장부에 보존한다. 진행 상황을 알린 뒤 같은 실행을 이어간다. 재시작이나 모델 호출 제한 이후에는 기존 체크포인트에서 미완료 단계부터 재개한다. 이미 검증된 PDF와 완료한 단계는 재사용하고 같은 실행을 중복으로 시작하지 않는다.

Windows에서 받은 기관 PDF를 인계하는 실행은 [Windows PDF 인계 절차](../../tools/kyonggi-library-collector/README.md#windows에서-받은-pdf를-ubuntu로-인계)를 따른다. Ubuntu에서는 완성된 실행 폴더의 장부와 PDF를 검증해 동일 실행 ID로 등록하고 인용 추적부터 이어간다.

세션이 닫혀 있으면 허용된 범위에서 브라우저를 열고 수집을 시도한다. 사용자 로그인이나 추가 인증이 실제로 필요한 경우, 로그인 전까지 가능한 단계를 진행하고 이어갈 지점을 보존한다. 사용자 입력이 접수되면 같은 실행을 이어간다. 사용자 입력 또는 외부 복구가 필요한 장애로 멈추면 막힌 단계와 실제 오류, 재개 지점을 보고한다. 완료 상태는 검수와 공유본 확인까지 끝난 실행에만 사용한다.
