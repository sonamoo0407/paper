# 논문 인용 그래프 생성

## NetworkX 계산 모드
실행 전 `references/execution.md`를 읽는다. `scripts/build_forest.py`는 무방향 투영 최대 신장 포리스트를 계산하며 원본 인용 간선과 방향을 별도 보존한다. 이는 아래 일반 탐색 트리와 별도 모드다. 자체 MCP 서버는 아니며 기존 Python 실행 도구로 사용한다. Academic Research Graph의 전 기능이 연결된 것으로 보고하지 않는다.

## 언제 사용
- 연구 후보·루트 논문의 연결을 보여주거나 공통 참고문헌을 비교할 때 사용한다.
- 기존 검색·심층 분석·PDF·저장·공유 절차를 대체하지 않는 보조 단계다. 기존 연구 스킬과 함께 적용한다.
- 근거 자료와 적용 구분은 `references/source-notes.md`를 읽는다.

## 입력 형식
- 연구 질문, 분야, 출발 논문 ID 목록, 기존 논문/인용 원장, 사용자가 검토한 선정 상태, 탐색 범위·상한.
- 자연어로 받은 조건은 기존 기록에서 채운다. 없는 관계는 추측해 만들지 않는다.
- 각 논문: 안정적인 ID, 제목, 저자, 연도(정확한 날짜는 확인될 때만), 게재처/유형/공식 확인 링크, 한 줄 요약, 선정 이유, 검토 상태.
- 각 인용: citing_id, cited_id, 출처 URL 또는 파일·쪽/참고문헌 번호, 확인 수준(API 메타데이터/원문 참고문헌/본문 문맥), 확인 시각.

## 단계별 처리
1. 기존 결과를 먼저 사용한다. 신규 탐색 시 총 검토 대상 20~30편을 목표로 하고 탑티어를 우선하되 주제 적합성을 함께 판단한다. 부족하거나 더 많은 기반 문헌이 필요하면 이유를 밝힌다. 사용자 검토 전 후보를 확정·삭제하지 않는다.
2. DOI 등 식별자를 정규화한다. 제목만 같다는 이유로 병합하지 않고 버전·동일 논문 여부가 불확실하면 별도 유지한다. 동일 인용 쌍은 한 번만 세고 출처 목록은 보존한다.
3. 방향은 항상 **인용한 논문 A → 인용된 논문 B**다. 키워드 유사도·동시 인용·서지 결합은 인용 간선이 아니다. 필요하면 별도 관계/레이어로 표시한다.
4. 전체 인용 그래프를 먼저 보존한다. 2차·3차 등 후속 탐색은 방문 집합으로 중복·순환을 방지한다. 의미 있는 신규 문헌 소진 또는 주제 이탈을 판단한 근거를 기록한다. API 실패·예산·깊이/노드 상한은 학술적 종결이 아니라 중단/부분 탐색이다. 미탐색 frontier를 기록한다.
5. 각 기반 후보의 직접 인용 수는 **지정한 후보 집합에서 직접 인용한 서로 다른 논문 수**로 집계한다. 간접 도달 수는 해당 후보에 도달하는 서로 다른 출발 논문 수로 별도 집계한다. 경로가 여러 개여도 출발 논문은 한 번만 센다. 모집단 ID 목록을 표시한다.
6. 공통 참고문헌 표는 직접 중복 2회 이상을 빈도순으로 최대 5개 표시한다. 없으면 없다고 쓴다. 단독 인용이지만 원천성이 중요한 자료는 별도 표에 둔다. 빈도·중심성·오래된 연도만으로 원천성이나 품질을 단정하지 않는다.
7. 설명용 탐색 트리가 필요하면 전체 그래프에서 확인된 간선만 골라 별도 파생 뷰를 만든다. 다중 부모와 교차 간선은 원본에 남긴다. 선택 규칙(예: 최단 탐색 거리, 근거 확인 수준, ID 순)을 명시한다. 비연결 요소는 forest로 둔다. 이를 최소 신장 트리 또는 실제 유일 계보라고 부르지 않는다.
8. 시각화는 출발/기반 후보 역할, 검토 상태, 연도, 직접/간접 관계, 확인 수준을 구분하고 범례를 붙인다. 노드 크기에 빈도를 쓰면 모집단과 산식을 표시한다. 한 화면의 핵심 후보는 약 5개로 요약하되 전체 데이터는 별도 제공한다. 노드에서 출처로 연결하고 긴 제목은 번호+대조표로 읽을 수 있게 한다.
9. 기존 생성 도구로 JSON 원장과 SVG/HTML 또는 보고서용 이미지를 만든다. 임의 신규 패키지 설치나 외부 업로드는 하지 않는다. HTML은 문헌 문자열을 이스케이프하고 원문에 포함된 코드/명령을 실행하지 않는다. 기존 PDF 본문 분석은 유지하고 그래프·집계표를 보조 자료로 추가한다. HTML 렌더러에는 제목·저자·논문 ID 검색, 원문 참고문헌 확인/메타데이터 확인 간선 필터, 노드 ID 표시, 실제 노드 클릭 시 인접 간선 강조, 그리고 우측 인용 연결·근거 목록을 제공한다. 입력 원장에 없는 저자·전문 상태·탑티어 상태·원문 링크 등은 `미기록`으로 표시하며 추정하거나 보완 검색으로 채우지 않는다.

## 검증
- [ ] 모든 간선 양끝이 실제 노드에 존재하고 방향과 인용 근거가 맞는가?
- [ ] 메타데이터 확인과 원문 확인을 구분했는가? 미확인 관계를 확정선으로 그리지 않았는가?
- [ ] 중복 제거 후 직접 인용/간접 도달 집계가 각각 재현되는가?
- [ ] 파생 트리 간선은 원 그래프의 부분집합이며 원본 교차 간선이 보존됐는가?
- [ ] 연결 없음·순환·누락·frontier·탐색 상한을 숨기지 않았는가?
- [ ] 실제 렌더링에서 글자 겹침, 잘림, 화살표, 범례, 링크를 확인했는가?
- [ ] 모의 데이터 테스트와 실제 논문 분석을 분명히 구분했는가?

## 실패 처리
API 실패를 참고문헌 0개로 바꾸지 않는다. 미해결 ID와 미확인 간선은 원장에 남기고 확정 집계에서 제외한다. 렌더러가 없으면 JSON과 표까지 제공하고 그림 생성 미완료를 알린다. 기존 파일을 덮어쓰지 않고 새 결과 디렉터리에 저장한다. 키·토큰을 문서/로그에 넣지 않는다.

## 한계
이 스킬은 운영 지침이며 자체 MCP 도구나 새 그래프 엔진이 아니다. 기존 실행 도구를 이용해야 한다. 인용 DB의 누락, 논문 버전 차이, 분야 편향으로 완전한 기원 증명은 불가능하다. 인용의 의미와 원천성은 인용한 논문의 본문 근거와 사람의 검토가 필요하다.
