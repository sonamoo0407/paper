# 원자료와 연구용 적용 구분

원자료: 사용자가 제공한 `5ppt(양식).pptx`, 총 8슬라이드. PPT 텍스트/표를 추출하여 확인했다. 예제 발표이며 이 문서만으로 알고리즘의 실험적 성능을 검증할 수 없다.

| 슬라이드 | 확인한 내용 | 적용 범위 |
|---|---|---|
| 1, 3 | wBAN 환경의 spanning tree 기반 에너지 효율적 routing, 센서 전력·mobility·QoS 문제 | 논문 그래프가 아닌 통신 네트워크 사례임을 구분 |
| 4 | Energy efficiency와 reliability의 trade-off | 시각적 간결성과 관계 보존의 균형은 우리 연구용 해석이며 PPT의 직접 결론 아님 |
| 5 | MAC/Network cross-layer, TDMA, WASP, CICADA, spanning tree | 이름을 인용 그래프 알고리즘으로 그대로 적용하지 않음 |
| 6 | child의 parent 선택 우선순위 문제, 센서 특성·전력 표 및 노드 예시 | 선택 기준을 명시한 설명용 트리라는 아이디어만 차용. 논문은 다중 부모 허용 |
| 7 | Experiment 제목만 있음 | 실험 결과·성능 수치 근거 없음 |
| 8 | 센서 특성에 따른 우선순위와 spanning tree 구성 제안 | 원자료의 주장으로만 취급, 검증된 우수성으로 과장하지 않음 |

인용 방향, ID 정규화, 집계 모집단, 원본 그래프/파생 트리 분리, 인간 검토는 사용자의 연구 요구와 데이터 보존을 위한 **추가 설계**다. PPT에 이러한 논문 분석 규칙이 직접 들어 있다고 표현하지 않는다.

## 최소 모의 검증 사례
실제 논문으로 제시하지 않는 fixture: 출발 A,B; 간선 A→X, B→X, A→Y, Y→X. A→X 중복 입력 1개 추가.
- 중복 제거 후 간선 4개; X 직접 인용 출발 수=2, 간접 포함 도달 출발 수=2(3으로 세면 오류).
- Y 직접 인용 출발 수=1. 공통 참고문헌 표에는 X만 포함.
- 설명용 트리/forest에서 간선 일부가 빠져도 전체 원장에는 4개 보존.
- X→A 순환을 추가해도 탐색 종료. 미해결 Z나 API 실패를 실제 leaf로 확정하지 않음.
