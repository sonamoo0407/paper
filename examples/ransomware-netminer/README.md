# NetMiner로 랜섬웨어 인용망 검산

[9월 28일 이관본 그래프](../../vm-migration-backup-20260928/graph-renderer/graphs/graph-output/graph.json)의 10개 노드와 기존 원장에 원문 확인으로 기록된 14개 인용 관계를 사용했다. 화살표는 인용한 논문 → 인용된 논문이다.

1. NetMiner 5에서 [인접 행렬 CSV](ransomware-citations-matrix.csv)를 1-mode 방향성 네트워크로 불러온다. 행은 출발점, 열은 도착점이고 1은 인용 관계다. 10개 노드와 14개 링크인지 확인한다.
2. **네트워크 → 중심성 → Betweenness**를 실행한다. 보고서의 최대값은 소수 셋째 자리까지 `0.032`였고, 개별 노드 결과는 **[T] Betweenness Centrality** 탭에 표시된다.
3. [인용 관계 목록 CSV](ransomware-citations.csv)에서 각 화살표를 확인할 수 있다. 고립 노드인 R1-05도 분석에 포함하려면 인접 행렬을 사용한다.

| 순위 | 중간 논문 후보 | 방향성 매개중심성 |
| ---: | --- | ---: |
| 1 | ShieldFS | 0.03241 |
| 2 | Redemption | 0.02546 |
| 3 | PayBreak | 0.01157 |

표는 같은 인용망에서 별도로 계산한 값이다. 각 출발·도착 논문 쌍에서 후보를 통과하는 최단 경로의 비율을 구해 더한다. 예를 들어 최단 경로 세 개 중 한 개를 차지하면 해당 쌍에서 1/3이다. 방향성 정규화 분모 72는 후보 자신을 뺀 9개 출발점 × 각 출발점과 다른 8개 도착점이다. ShieldFS의 경로 기여도 합은 7/3이다. 이를 72로 나누면 0.03241이다.

NetMiner에는 인용망을 입력했다. 실제 인용 목적과 연결 역할은 논문 본문을 검토해 별도로 기록한다.
